# Changelog

## 1.0.0 (2026-10-29)

The first public release.

- Type a shortcut such as `;addr` and press a hotkey (default Ctrl+Space) to replace it with its full message. The hotkey is kept from the app you're typing in.
- Optional automatic expansion after a space, punctuation, Enter or Tab.
- Placeholders: `{date}`, `{time}`, `{clipboard}` and `{cursor}`.
- Instant pasting (your clipboard is put back afterwards) or typing at a speed you choose.
- Settings window with search, light and dark modes, a hotkey recorder, and import and export of snippets.
- Runs in the system tray, with Pause / Resume, and can start with Windows.
- Available as a single `TextExtender.exe`, no Python needed.
